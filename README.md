# FLUX Support Bot

FLUX Discord 봇의 서버 관리 및 커뮤니티 기능을 담당하는 CommonJS 기반 Discord 봇입니다.

## 서버 구성

| 서버 | 서버 ID | 용도 |
| --- | --- | --- |
| 친목 서버 | `1538513625730383902` | 밸런스게임, idle chat, 레벨·코인·출석·친구 등 커뮤니티 기능 |
| 봇 서포트 서버 | `1525458537139146812` | 봇 운영 지원 및 후원/랭킹 관리 기능 |

## 슬래시 커맨드 등록 범위

`npm run deploy` 실행 시 커맨드는 다음 범위로 등록됩니다.

- 전역 커맨드: 입장·퇴장 채널, 입장 역할, 등급 역할, 별명 관리, 경고, 추방, 타임아웃, 제재 채널 관리
- 친목 서버 전용: 밸런스게임, idle chat, 레벨·코인·출석·친구 등 커뮤니티 기능
- 봇 서포트 서버 전용: 후원금액, 랭킹채널

전역 커맨드는 봇이 참여한 모든 서버에 표시되며, 실제 사용 가능 여부는 커맨드별 권한 및 서버 제한을 따릅니다.

## 실행

```bash
npm start
```

슬래시 커맨드 등록 또는 갱신:

```bash
npm run deploy
```

## 환경 변수

`.env` 파일에 다음 값을 설정해야 합니다.

```env
DISCORD_TOKEN=봇_토큰
WELCOME_CHANNEL_ID=기본_입장_채널_ID
GOODBYE_CHANNEL_ID=기본_퇴장_채널_ID
```

프로젝트 설정에 따라 `DATABASE_URL`, `HF_TOKEN` 등 추가 환경 변수가 필요할 수 있습니다.
